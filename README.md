# React: работа с API

Учебный проект на React с двумя независимыми примерами загрузки данных из API.

## Запуск проекта

Требуется установленный Node.js и npm.

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Задание 1 — Лента новостей

- Загружает публикации из [DummyJSON Posts API](https://dummyjson.com/posts) через `fetch`.
- Показывает заголовок, текст, теги, просмотры и реакции.
- Выводит посты с помощью `.map()`.
- Загружает по 10 публикаций за раз: следующую порцию можно получить кнопкой «Загрузить ещё».
- Позволяет отфильтровать загруженные публикации по тегу.

## Задание 2 — Random Cat

- Получает случайное изображение кота из [The Cat API](https://api.thecatapi.com/v1/images/search).
- Загружает кота при открытии экрана и по нажатию кнопки «Новый кот».
- Показывает состояние загрузки и ошибки запроса.
- Позволяет добавлять котов в избранное, открывать сохранённое изображение и удалять его из коллекции.

Оба задания доступны через переключатель в верхней части страницы. Интерфейс адаптирован для мобильных экранов.

## Стек

- React 18
- TypeScript
- Vite
- DummyJSON Posts API
